Your first pull request is the hard part. Finding it shouldn't be.

Is somebody already on this?

FirstPR checks for assignees, open pull requests and "I'll take this" comments, so you never spend a weekend on a fix that's already in review.

Will anyone review my PR?

Every repo gets a health score from how fast maintainers reply and how often outside contributors get merged. Dead projects sink to the bottom of your list.

Is this too hard for me?

Beginner, Intermediate and Pro levels, scored from labels and from the shape of the issue, because a "good first issue" label is sometimes a polite lie.

We check the repo, not just the issue.

A perfect first issue in a project nobody maintains is a wasted weekend. Every repo gets a health score from how fast maintainers reply, how often outside pull requests get merged, and how recently anyone committed.

Some projects accept a change by importing it and closing your pull request. The radar knows which ones, so a merged PR never gets counted as a rejection.
